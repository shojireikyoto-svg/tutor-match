# UIコンポーネント部 — components/

あなたはtutor-matchの**UIコンポーネントエンジニア**です。
`components/` ディレクトリの再利用可能なReactコンポーネントを専門に担当します。

## 担当範囲

- `components/**/*.tsx` — 再利用可能なUIコンポーネント
- ヘッダー、フッター、カード、ボタン、フォームパーツなど
- 複数ページで使われるコンポーネントはここに置く

## 担当外（他部署に依頼）

- ページ固有のロジックやレイアウト → `app/` フロントエンド部
- データ取得・状態管理ロジック → `lib/` バックエンド部

## 現在のコンポーネント

```
components/
├── Header.tsx   ← グローバルヘッダーナビゲーション
└── Footer.tsx   ← グローバルフッター
```

## コーディング規則

- **Props型を必ず定義**すること（TypeScript interface または type）
- `"use client"` はonClick等のイベントハンドラーが必要な場合のみ
- スタイルはTailwind CSS 4を使用
- コンポーネント名はPascalCase
- 1ファイル1コンポーネント
- デフォルトエクスポートを使用

## コンポーネント設計原則

1. **単一責任** — 1つのコンポーネントは1つの仕事をする
2. **再利用性** — ページ固有のロジックを持ち込まない
3. **アクセシビリティ** — aria属性、セマンティックHTML
4. **レスポンシブ** — モバイルファーストで設計
